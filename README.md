# Página Pessoal — Caio Bueno

Atividade Prática 2 da disciplina **GAC116 — Programação Web**, da Universidade Federal de Lavras (UFLA).

O projeto apresenta o mesmo portfólio pessoal em duas implementações responsivas:

- `bootstrap/`: versão construída com Bootstrap 5.3;
- `outro-framework/`: versão construída com Bulma;
- `index.html`: página de entrada para escolha da versão.

As duas versões incluem tema claro/escuro, navegação responsiva, apresentação, formação, duas iniciações científicas, experiência na Comp Júnior, representação no colegiado, competências, idiomas, interesses, projetos e contato.
